# 隐私政策

**适用产品：** JO-符号转换（JO Symbol Converter）
**最后更新：** 2026-11-14

JO-符号转换是一个本地文本处理工具。本政策说明本应用如何处理你的数据。

## 一、我们收集什么

**不收集任何个人信息。**

本应用不收集、不上传、不共享你的文本内容、设备信息或使用记录，也不包含统计分析、广告、崩溃上报或任何第三方追踪 SDK。

## 二、数据保存在哪里

- 你输入的原文、转换结果、草稿、历史记录和设置，全部保存在本机，不会离开设备。
- Windows 版本的数据目录为 `%APPDATA%\JO-Beacon\JO-符号转换`。
- 卸载应用不会自动删除该目录；你可以随时手动删除，删除后数据不可恢复。

## 三、网络访问

- **Microsoft Store 版本不发起任何网络请求。**
- 从 GitHub 分发的版本在你**主动点击“检查更新”**时，会访问 GitHub Releases API 获取最新版本号，并可能打开浏览器显示发布页面。该请求只包含常规 HTTP 头，不包含你的文本内容或任何标识信息。

## 四、第三方组件

应用内置思源黑体（Source Han Sans），按 SIL Open Font License 1.1 授权使用，不涉及数据传输。其余第三方组件见应用内“关于 → 第三方开源许可证”。

## 五、儿童隐私

本应用不收集任何用户数据，因此也不收集儿童的个人信息。

## 六、政策变更

本政策如有更新，将发布在本页面，并更新页面顶部的“最后更新”日期。

## 七、联系方式

如有疑问，请通过 GitHub Issues 联系：
https://github.com/JO-Beacon/JO-Symbol-Converter/issues

# Privacy Policy

**Product:** JO Symbol Converter
**Last updated:** 2026-11-14

JO Symbol Converter is a local text-processing tool. This policy explains how the app handles your data.

## 1. What we collect

**Nothing.** The app does not collect, upload, or share your text, device information, or usage data. It contains no analytics, advertising, crash-reporting, or third-party tracking SDKs.

## 2. Where data is stored

- All input text, conversion results, drafts, history, and settings stay on your device.
- On Windows, data is stored in `%APPDATA%\JO-Beacon\JO-符号转换`.
- Uninstalling the app does not delete this folder automatically. You can delete it at any time; deleted data cannot be recovered.

## 3. Network access

- **The Microsoft Store build makes no network requests.**
- The GitHub-distributed build contacts the GitHub Releases API only when you explicitly choose "Check for updates", to read the latest version number, and may open a browser to show the release page. That request carries standard HTTP headers only — never your text or any identifier.

## 4. Third-party components

The app bundles Source Han Sans, licensed under the SIL Open Font License 1.1. Other third-party components are listed in the app under "About → Third-party open source licenses". None of them transmit data.

## 5. Children's privacy

The app collects no user data, and therefore collects no personal information from children.

## 6. Changes

Any update to this policy will be published on this page with a revised "Last updated" date.

## 7. Contact

Questions? Open an issue at:
https://github.com/JO-Beacon/JO-Symbol-Converter/issues
